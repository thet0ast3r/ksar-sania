# Ksar Sania · Merzouga

Comic-style 3D playground (Svelte 5 + Threlte + three.js): walk around Ksar Sania as a red-bearded adventurer, hop into the white Duster or the quad, and collect dates (Datteln) across the dunes of Erg Chebbi. Time slider runs the full 24h, with moon and stars at night.

**Play:** https://thet0ast3r.github.io/ksar-sania/

Controls: WASD/arrows · E enter/exit · Space jump/handbrake · R flip · drag to look. On phones: left stick + buttons.

```
npm i && npm run dev
```
